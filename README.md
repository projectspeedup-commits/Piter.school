# Piter.school — школьные задания Петра

Сайт с заданиями и разборами для Петра (6 класс):
**https://projectspeedup-commits.github.io/Piter.school/**

## Как пользоваться сайтом (для Петра)

1. На главной странице выбери предмет и задание (сверху есть поиск 🔍).
2. Прочитай раздел **«Разбор»** — там объяснение по шагам и решённый пример.
3. Реши задания раздела **«Самостоятельная работа»** на бумаге.
4. Проверь себя: нажми кнопку **«Показать ответы»**. Не раньше! 🙈

## Как добавить новое задание

Всё просто — **положи .md файл в папку предмета** и запушь в `main`:

```
Русский язык/
  ДЗ-03-падежи.md      ← новый файл, папку-предмет можно создать новую
Математика/
  ДЗ-17-простые-множители.md
```

Требования к .md файлу:

- Первая строка — заголовок: `# ДЗ 18. Название темы` (он попадёт в список на главной).
- Раздел самостоятельной работы — заголовок `## Самостоятельная работа`.
- Раздел ответов — заголовок `## Ответы` (на сайте он будет скрыт кнопкой
  «Показать ответы»).
- Формулы можно писать в LaTeX: `$a^2 + b^2 = c^2$` — отрендерятся автоматически.
- Таблицы, блоки кода, списки — обычный Markdown.

После пуша в `main` GitHub Action сам пересоберёт сайт и обновит его
(обычно 1–2 минуты). Новый файл появится на главной странице автоматически.

### Локальная сборка (необязательно)

```
python build.py
```

Скрипт сканирует папки-предметы, находит все `.md` и собирает сайт в папку
`site/` (файл `site/manifest.json` — список заданий). Открыть локально можно
через любой статический сервер, например: `cd site && python -m http.server`.

## Как устроена публикация (GitHub Pages)

- Исходники и задания — в ветке `main`.
- Workflow `.github/workflows/pages.yml` при каждом пуше в `main` запускает
  `build.py` и выкладывает содержимое папки `site/` в ветку **`gh-pages`**.
- В настройках репозитория (Settings → Pages) источник: ветка `gh-pages`,
  папка `/ (root)`.
- Сайт чисто статический (HTML/CSS/JS, Jekyll отключён файлом `.nojekyll`),
  Markdown рендерится в браузере.
