# Piter.school — школьные задания Петра

Здесь лежат задания и разборы для Петра (6 класс).

Как пользоваться:
1. Открой нужный предмет и файл задания.
2. Прочитай раздел **«Разбор»** — там объяснение по шагам и решённый пример.
3. Реши задания раздела **«Самостоятельная работа»** на бумаге.
4. Проверь себя по **«Ответам»**.
